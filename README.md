# Pen-plotter
A 180mm × 106.5mm pen plotter, driven by four 28BYJ-48 stepper motors. It can run on any microcontroller with at least 12 output pins, but all my code is written for the Arduino Uno.

Items list
2 (608-2RS bearings)
1 (Pen)
4 (28BYJ-48 stepper motors)
~200g (filament)
2 (M3 bolts any size)
2 (M3 bolts 7mm or less)
2 (M3 bolts 10mm or less)
1 (Power supply ~5 volts and at least 2amps)
